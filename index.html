    • Introduction to HTML

    Back to Top

    HTML stands for HyperText Markup Language. It is the standard language for creating web pages. HTML describes the structure of a web page using markup. It consists of a series of elements that tell the browser how to display content.

    HTML Elements

    Back to Top

    HTML elements are the building blocks of HTML pages. They are represented by tags, which are enclosed in angle brackets. For example, <h1> is a tag for a heading element. Elements can have attributes that provide additional information about the element.

    Inspect an HTML Element:

    Right-click on an element (or a blank area), and choose "Inspect" to see what elements are made up of (you will see both the HTML and the CSS). You can also edit the HTML or CSS on-the-fly in the Elements or Styles panel that opens.

    HTML Attributes

    Back to Top

    HTML attributes provide additional information about HTML elements. They are specified within the opening tag of an element and consist of a name-value pair.

    Creating Links

    Back to Top

    To create a link in HTML, you can use the <a> tag. The href attribute specifies the URL of the page the link goes to. For example:

    <a href="https://www.example.com">Visit Example</a>

    This will create a link that says "Visit Example" and takes the user to "https://www.example.com" when clicked.
